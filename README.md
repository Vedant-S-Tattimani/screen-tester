# Screen Tester

A production-grade display diagnostic and screen inspection web utility built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **29 Display Tests**: Dead pixel, backlight bleed, color accuracy, screen tearing, refresh rate, motion blur, ghosting, HDR capability, resolution checker, gamma, blooming, viewing angle, and more.
- **Systematic Inspection Workflows**:
  - 5-Minute Quick Check for immediate post-purchase validation
  - Full Diagnostic Suite for in-depth analysis
  - Tailored inspection workflows for Used Monitors, Gaming Displays, and OLED screens
- **Full Internationalization (i18n)**: English, German, and Korean localization with Next-Intl.
- **Diagnostic Observation Logging**: Mark tests as PASS, CHECK, or ISSUE with automated summary report generation.
- **Responsive Calibration Patterns**: Precise 16:9 and borderless fullscreen test canvases with zero clipping.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to launch the application.
